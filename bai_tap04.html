Đây là trang web của tôi

Chào mừng đến với trang web của tôi. Đây là một ví dụ về cách sử dụng thẻ
img để hiện thị hình ảnh trên một trang web
        

Trên đây là một hình ảnh ngẫu nhiên được sử dụng từ trang web unsplash.
Tôi đã thay đổi kích thước hình ảnh bằng cách chỉnh độ rộng chiều cao
width 400 và height 600. Thêm mô tả hình ảnh thuộc tính alt với nội dung
